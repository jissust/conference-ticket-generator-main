# CONFERENCE TICKET GENERATOR

Automatic ticket generator by loading some data into a form.


## Functionalities

- form that requests image, name, email and GitHub username, based on that data it generates a ticket.


## Technologies used

- React 19
- Tailwinc CSS
- TypeScript 
- JavaScript (ES6+)
- HTML y CSS

## Run local project
Clone project:
        
        git clone https://github.com/jissust/conference-ticket-generator-main.git

Go to the project 

        cd conference-ticket-generator-main

Run
        
        npm install

Followed by 
        
        npm run dev
